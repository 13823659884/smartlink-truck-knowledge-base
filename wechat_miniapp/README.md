# 鱼快创领中重卡知识问答微信小程序

这是可直接导入微信开发者工具的原生小程序工程，使用 WXML、WXSS 和 JavaScript，实现：

- 鱼快创领官方 Logo、品牌蓝、公司名称与品牌主张。
- 原创蓝白重卡与智能网联道路主视觉，适配手机端尺寸并保存在本地资源中。
- 车型与用/养/修/保场景选择。
- 车辆专业问题只基于企业知识库生成，普通问题由通用模型自主回答。
- 流式显示回答，并支持“快速问答（豆包 Lite）/深度诊断（Kimi K3）”切换。
- 问题任务分类、故障码结构化精确索引，以及 SQLite FTS5 + Qdrant 多模态向量混合召回。
- 小程序显示当前任务类型、检索路线、采用资料数和检索耗时。
- 连续对话、相关问题和新建对话。
- 回答按分析结论、处理步骤、安全提示分段，并展示原始文档、页码和参考内容。
- 拍照或选择图片，本地识别仪表文字、故障码和图纸内容后检索知识库。
- 显示证据充足度、安全等级、检查清单和需要继续确认的问题。
- 诊断追问提供“是 / 否 / 不确定”按钮，手动输入短回答也会自动承接上一轮上下文。
- 资料来源下载与 `wx.openDocument` 打开。
- 点赞、点踩反馈。
- 可配置知识库服务地址。
- 设置页显示知识库解析与 OCR 覆盖情况。

## 导入

1. 安装并打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择仓库中的 `wechat_miniapp`。
4. 没有正式 AppID 时先使用测试号；有 AppID 后替换 `project.config.json` 中的 `appid`。
5. 开发阶段在“详情 - 本地设置”中勾选“不校验合法域名、web-view（业务域名）、TLS版本以及HTTPS证书”。

## 接口地址

- 开发者工具与后端在同一台电脑：`http://127.0.0.1:8009`
- 真机和电脑在同一 Wi-Fi：在“设置”填写电脑 WLAN 地址，例如 `http://192.168.63.102:8009`，并将后端监听地址改为局域网可访问。
- 正式发布：使用 HTTPS 域名，并在微信公众平台配置 request、downloadFile 合法域名。

火山方舟密钥始终保存在 `knowledge_base/.env`，不要写入小程序工程。

品牌信息与 Logo 来源于鱼快创领官网公开页面：`https://www.smartlink.com.cn/`。Logo 本地副本位于 `assets/smartlink-logo.png`，小程序运行时不依赖官网外链。

车辆主视觉位于 `assets/smart-truck-hero.jpg`，由内置图像生成工具原创生成，不含第三方车标、文字或水印。
